## 0.1.0

First release. Pure Dart: nothing here imports Flutter, so the same contracts
compile in a server, a CLI or a plain `dart test` run. The Flutter bindings
live in [`pillar_flutter`](../pillar_flutter).

### Dependency injection

- `PillarContainer` — registration and resolution, with factory, singleton,
  lazy singleton and async singleton lifetimes.
- Scopes: `openScope()` opens a child container that reads through to its
  parent, and shadows a registration for that scope only.
- `getAsync` and `ready()` for dependencies built asynchronously. Concurrent
  calls for the same dependency share one future, so the factory runs once.
- `PillarModule` and `installModules` to group registrations.
- `Pillar` — a root container for apps that want one, rather than a mandatory
  global.
- Disposal: `unregister` and `dispose` run registered disposers, scopes first.
- Errors that say what went wrong, all under a sealed `PillarDiError`:
  `DependencyNotFoundError`, `DependencyAlreadyRegisteredError`,
  `CircularDependencyError`, `DependencyNotReadyError`,
  `ContainerDisposedError`, `ModuleCycleError`.

### Clean architecture contracts

- `BaseEntity`, `BaseRepository`, `BaseUseCase` (with `NoParamsUseCase`,
  `SyncUseCase`, `SyncNoParamsUseCase`), `BaseService` and
  `InitializableService`.

### Error handling

- `Failure` types for expected outcomes (`ServerFailure`, `NetworkFailure`, …)
  and exception types for the unexpected.
